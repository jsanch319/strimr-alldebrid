# Stremio discovery and English audio

Use the existing Settings → Playback → Stremio Add-ons screen to install your personally configured, authorized manifest. Its private configuration stays in Keychain. Results are requested with the movie IMDb ID or exact series `IMDb:season:episode` identifier. Strimr cannot reproduce another app's source count unless both use the same installed manifest/configuration, account, filters, identifiers and provider response. No private manifest or live account was used for automated tests.

The previous implementation truncated responses at 100 rows, required a matching filename for raw hashes, ignored fileIdx, rejected abbreviated filenames and stopped manual discovery after finding a library match. Discovery now retains the full response within the existing one-MiB transport limit and preserves URL/infoHash/fileIdx/tracker and supported behavior-hint information. Missing, generic and opaque filenames can rely on the exact add-on request identity. Explicit conflicting IMDb/TMDb IDs, movie years, seasons/episodes or combined episode files remain blocked. Canonical title aliases and meaningful colon-suffix titles cover releases such as The Rings of Power. Native MKV support is not rejected merely because `notWebReady` is true.

The manual picker fetches add-on results alongside existing library matches and displays generated credential-free quality/index/language labels. Protected/DRM, embedded/external-player, custom-proxy-header and malformed/incompatible streams are displayed disabled with safe reasons. It does not extract protected streams or bypass DRM. Raw response labels, signed URLs and proxy credentials are never copied to public display models or logs.

Raw infoHash sources use the documented AllDebrid magnet import and existing polling/resume/player architecture. fileIdx is retained as a torrent selection hint and distinct discovery identity. AllDebrid's flattened file tree does not expose standard torrent ordinals: **Strimr never maps fileIdx to that tree's array position or picks the largest video**. Once the bound magnet is ready, actual file metadata must identify the requested episode. A bare video.mkv in a season pack cannot be mapped safely and will not be played. Existing submitted hashes are reused rather than re-uploaded for another episode. This API limitation means some index-only packs remain unplayable until their ready files can be identified; an authorized resolved HTTPS stream is preferable for those sources.

Always Prefer English Audio already exists under Settings → Playback → Audio and remains on by default. Explicit provider language fields/flags and release audio markers are **unverified ordering hints**: English, multilingual, unknown, then other advertised languages, with 4K → 1080p → 720p within each group. Disable the preference for quality-only ordering. A title containing the word English never establishes a language. No source is discarded merely for being foreign-language or unknown.

Actual player track language metadata selects the main English track over a foreign default, commentary or description. Manual track choices remain authoritative. If English is absent, Audio & Subtitles offers Choose Another Source; the manual picker includes all supported matches. Auto Play may inspect other already-ready files using the existing bounded native inspector. A metadata-verified English alternative is now offered for confirmation rather than silently replacing the source. Confirmation saves the current exact-second position and uses the existing resume/Simkl path. The inspector cannot prove English in every MKV/custom format; source labels are never a guarantee, and no dub is synthesized.

Tests use credential-free realistic Stremio fixtures (missing filenames, multilingual and foreign streams, repeated hashes with different indices, unsupported/protected/header sources and conflicting episodes). Live Torrentio response parity, actual track selection in The Rings of Power, source switching/resume and Simkl delivery still require a signed iPhone with the user's own configured authorized sources.
